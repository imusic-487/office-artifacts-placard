Entry for the [Office Artifacts: The One-Line Placard Contest](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) on [make.fun](https://make.fun).

`main.py` writes a single museum placard line to `/output/entry.txt`: a
stapler, recast as a ritual binding device of a long-vanished Department
of Records, its bite having sealed ten thousand memos, none of them ever
read. The placard is one line of 173 characters, within the 1–180 limit.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network, no secrets, nothing read from outside the repo.
